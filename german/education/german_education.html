Achtung: Das war eine Phishing-Simulation

Sie haben auf eine E-Mail aus einer Sicherheits-Awareness-Simulation geklickt. Keine Sorge: Es wurden keine Daten kompromittiert. Dies ist ein sicherer Moment zum Lernen.

Warnsignale, auf die Sie achten sollten

  • Erzeugter Zeitdruck oder Drohungen („Ihr Konto wird gesperrt“).
  • Aufforderungen, sich über einen Link anzumelden oder Ihr Passwort zu bestätigen.
  • Die Absenderadresse passt nicht zur offiziellen Domain.
  • Unpersönliche Anreden oder Rechtschreib- und Grammatikfehler.
  • Links, deren tatsächliches Ziel nicht zum angezeigten Text passt.

So schützen Sie sich

  • Halten Sie inne, bevor Sie klicken. Prüfen Sie den Absender in Ruhe.
  • Geben Sie die offizielle Adresse selbst im Browser ein, statt dem Link zu folgen.
  • Aktivieren Sie die Zwei-Faktor-Authentifizierung, wo immer möglich.
  • Melden Sie verdächtige E-Mails an Ihr Sicherheits- oder IT-Team.
